# Ruby Algorithms & Problem Solving

A collection of algorithm and data structure problems solved using Ruby.

This repository documents my journey towards becoming a stronger software engineer through consistent problem-solving practice. It serves as both a record of my progress and a place to develop the analytical skills needed to write efficient, maintainable code.

## Goals

- Build strong problem-solving and algorithmic thinking skills.
- Understand common data structures and algorithmic patterns.
- Improve my ability to analyse time and space complexity.
- Write clean, readable, and idiomatic Ruby.
- Develop the confidence to approach unfamiliar problems independently.

## Approach

I prioritise understanding the problem and developing a solution before worrying about optimisation.

For each problem, I aim to:

1. Understand the requirements and identify edge cases.
2. Develop an initial solution, even if it isn't optimal.
3. Analyse its time and space complexity.
4. Identify bottlenecks and explore better approaches.
5. Implement and test the improved solution.
6. Document what I learned.

I believe understanding *why* a solution works is more valuable than simply memorising it.

## Problem Documentation

Each problem has its own directory containing the Ruby implementation and a README documenting the reasoning behind the solution.

Where relevant, the documentation covers:

- Problem statement and source
- Initial approach
- Optimisation process
- Time and space complexity
- Edge cases and tests
- Key lessons learned

Problems may come from different platforms, interview exercises, or independent practice.
